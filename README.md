# 🎮 Tic Tac Toe

A simple and interactive Tic Tac Toe game built using **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

- Two-player gameplay (X vs O)
- Winner detection
- Draw detection
- Restart/New Game option
- Responsive and user-friendly UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```text
tic-tac-toe/
│
├── index.html      # Main HTML file
├── style.css       # Styling
├── app.js          # Game logic
└── README.md       # Project documentation
```

## 🎯 How to Play

1. Player X starts the game.
2. Players take turns clicking on empty cells.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all cells are filled and no player wins, the game ends in a draw.
5. Click the "New Game" or "Reset" button to play again.

## 🔧 Installation

1. Clone the repository:

```bash
git clone https://github.com/gaddamdroneswarreddy/tic-tac-toe.git
```

2. Open the project folder:

```bash
cd tic-tac-toe
```

3. Open `index.html` in your browser.
